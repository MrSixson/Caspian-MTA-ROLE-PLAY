# Caspian RolePlay Website

Official public-facing website for Caspian RolePlay.

## Structure

- `index.html` — Persian RTL homepage
- `assets/css/style.css` — responsive dark navy, blue and gold visual system
- `assets/js/main.js` — mobile navigation and dynamic footer year
- `assets/img/favicon.svg` — Caspian monogram favicon

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.

## Before public launch

Confirm and update the official server connection address, launch status, rules, staff details, and any final community links. The current page intentionally does not invent server status, player counts, or connection details.

## Design

Persian RTL layout, responsive navigation, cinematic navy background, Caspian blue highlights and restrained gold accents.
